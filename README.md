# АС Дент — онлайн-запись в стоматологическую клинику

Дипломный проект: веб-приложение для стоматологической клиники. Пациенты
записываются на приём онлайн и ведут личный кабинет, администратор управляет
записями, врачами, услугами, расписанием и контактами клиники.

Построено на клиент-серверной архитектуре без фреймворков: PHP на сервере,
HTML/CSS/JavaScript в браузере, база данных SQLite.

## Возможности

**Пациент**
- регистрация и вход, согласие на обработку персональных данных;
- запись на приём: услуга → врач → свободное время по расписанию врача;
- личный кабинет: ближайший приём, будущие визиты, история посещений;
- отмена записи не позднее чем за 2 часа до приёма;
- изменение личных данных и смена пароля.

**Администратор**
- записи на приём: создание, перенос, отметка о состоявшемся приёме;
- пользователи: создание, изменение, блокировка, удаление;
- врачи — включая фото, которое пациенты видят на главной странице;
- услуги, цены и длительность приёма;
- расписание врачей по дням недели;
- контакты клиники;
- журнал действий пользователей.

**Главная страница** открыта для всех: услуги и цены, врачи, контакты клиники.

## Безопасность

- Пароли хранятся только в виде хеша Argon2id.
- Персональные данные (ФИО, email, телефон, дата рождения) шифруются
  алгоритмом XSalsa20-Poly1305 из библиотеки libsodium; ключ шифрования
  хранится отдельно от базы данных.
- Поиск пользователя по email — через отдельный HMAC-хеш («слепой индекс»),
  сам email при этом из хеша не восстановить.
- Защита от SQL-инъекций — подготовленные запросы PDO.
- Защита от CSRF — токен в каждом изменяющем запросе.
- Блокировка входа на 15 минут после 5 неверных попыток пароля.
- Права доступа проверяются на сервере для каждого действия.
- Два триггера в базе данных не допускают пересекающиеся по времени записи
  у одного врача или у одного пациента.
- На сайте есть согласие на обработку персональных данных, политика
  обработки данных и уведомление об использовании cookie (в соответствии
  с 152-ФЗ «О персональных данных»).

## Требования

PHP 8.1 или новее с расширениями `pdo_sqlite`, `sodium`, `mbstring`.

## Быстрый запуск (локально)

```bash
git clone https://github.com/IrinkaCode/Dental-clinic.git
cd Dental-clinic
php install.php 
```

Запуск сервера:

```bash
php -S localhost:8000 -t public
```

Откройте `http://localhost:8000`. В Windows то же самое делает `start.bat`.

## Размещение на хостинге

Нужен PHP 8.1+ с указанными выше расширениями и HTTPS. Корнем сайта должна
быть папка `public`, остальные папки (`src`, `config`, `database`) не должны
быть доступны из браузера. Папкам `database`, `logs` и `public/img/doctors`
нужны права на запись для веб-сервера. Перед запуском проверьте, что в
`config/config.php` стоит `'debug' => false`.

## Резервное копирование

Файл базы данных (`database/clinic.sqlite`) и файл ключей
(`config/config.php`) не хранятся в репозитории. Резервную копию нужно
делать для обоих файлов вместе: без ключей шифрования данные из копии
базы не расшифровать.
